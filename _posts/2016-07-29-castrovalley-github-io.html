castrovalley.github.io

A community site for Castro Valley, built as a Jekyll site on Github Pages so that anyone could contribute to it with a pull request rather than a CMS login.

The site collects the sort of local material that tends to be scattered across old forum threads and PDFs - a history of the town, an annotated community map, and a guide explaining how to contribute a page of your own.

Jekyll, Sass, Github Pages

Source available on Github.
